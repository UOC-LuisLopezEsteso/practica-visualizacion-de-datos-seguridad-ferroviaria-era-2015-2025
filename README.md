# Práctica de Visualización de Datos (UOC)

[era-csi-clean.csv](era-csi-clean.csv) es el conjunto de datos resultante del proceso de extracción, transformación y carga (ETL) realizado para la práctica. Contiene 297 registros y 26 columnas sobre seguridad ferroviaria en 27 países europeos entre 2015 y 2025.

Datos de origen de la Agencia Ferroviaria de la Unión Europea. [Common Safety Indicators (ERA)](https://www.era.europa.eu/domains/accident-incident/common-safety-indicators-csis).
